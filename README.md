# PDF朗読

iPhoneのSafariで動く、PDFを読み上げるWebアプリです。インストール不要・無料で使えます。

## できること

- iPhoneの「ファイル」アプリやiCloud Driveに入っているPDFを開く
- 日本語・英語の文章を読み上げる（再生 / 一時停止 / 停止 / 前の文 / 次の文）
- 読み上げ中の文を黄色で表示。文をタップするとそこから読む
- 速度（0.5〜2.0倍）と声の切り替え
- ページの移動。ページの終わりまで読むと次のページに進む
- 前回どこまで読んだかを覚えていて、同じPDFを開くと続きから読める

PDFはiPhoneの中だけで処理され、どこにも送信されません。

## iPhoneでの使い方

1. Safariでアプリのページを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」を押すと、アプリのように起動できます
3. 「PDFを開く」→ PDFを選ぶ → ▶︎ で読み上げ開始

声を良くしたいときは、iPhoneの「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」で、
「Kyoko（拡張）」や「O-ren（拡張）」などをダウンロードすると、アプリの「声」で選べるようになります。

## 公開のしかた（GitHub Pages）

1. GitHubでこのリポジトリを開き、「Settings」→ 左の「Pages」
2. 「Branch」で `main`、フォルダは `/ (root)` を選んで「Save」
3. 数分待つと `https://<ユーザー名>.github.io/pdf-reader-ios/` で開けるようになります

※ 無料プランではリポジトリがPublic（公開）である必要があります。アプリのコードが公開されるだけで、読み込んだPDFは公開されません。

## 注意

- スキャンした画像だけのPDF（文字データがないもの）は読み上げできません
- iPhoneの画面を消すと、読み上げが止まることがあります（Safariの制限）

## 構成

- `index.html` / `style.css` / `app.js` … アプリ本体
- `sw.js` / `manifest.webmanifest` / `icons/` … ホーム画面に追加・オフライン用
- `vendor/pdfjs/` … PDFから文字を取り出すライブラリ [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174（Apache-2.0）
